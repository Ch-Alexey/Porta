# Документация проекта Porta

**Porta** — кроссплатформенное приложение на .NET для передачи и синхронизации данных
между устройствами по принципу P2P (похоже на Dropbox, но без облака-посредника).
На старте — обмен по локальной сети, далее возможно расширение на другие сети.

Вся работа над проектом документируется здесь: цель — чтобы у каждой задачи был
контекст, а решения были прослеживаемы.

## Как устроена документация

| Каталог | Что внутри |

| [`adr/`](adr/) | Architecture Decision Records — зафиксированные архитектурные решения и их обоснование. Одно решение = один файл. |
| [`architecture/`](architecture/) | Описание архитектуры системы: слои, компоненты, потоки данных. |

| [`roadmap.md`](roadmap.md) | Этапы разработки и приоритеты. |
| [`glossary.md`](glossary.md) | Термины проекта, чтобы говорить на одном языке. |

## Ключевые решения (кратко)

- **UI:** Avalonia UI — единая кодовая база на все платформы, включая Linux desktop. См. [ADR-0001](adr/0001-ui-framework.md).
- **Платформы:** Windows, macOS, Linux, iOS, Android — равнозначно. См. [ADR-0002](adr/0002-target-platforms.md).
- **Архитектурный референс:** Syncthing (P2P-модель, pairing по ключам, протокол обмена блоками). См. [ADR-0003](adr/0003-syncthing-reference.md).
- **Разделение слоёв:** платформонезависимое ядро (`Porta.Core`) + тонкий UI. См. [architecture/00-overview.md](architecture/00-overview.md).
