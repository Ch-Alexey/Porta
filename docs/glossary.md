# Глоссарий Porta

Термины проекта — чтобы говорить на одном языке.

| Термин | Значение |
|---|---|
| **Устройство (Device)** | Экземпляр Porta на конкретной машине/телефоне. Равноправный участник сети. |
| **Device ID** | Идентификатор устройства = отпечаток его публичного ключа. |
| **Pairing (связывание)** | Процесс установления взаимного доверия между двумя устройствами (через QR/ссылку + одноразовый код). |
| **Доверенное устройство** | Устройство, чей ключ мы проверили и сохранили; с ним разрешён обмен. |
| **Хранилище (Storage/Folder)** | Папка на устройстве, участвующая в постоянной синхронизации. |
| **Разовая передача (Drop)** | Отправка выбранных файлов на другое устройство «как есть», без постоянной связи (аналог «закинуть в Загрузки»). Метаданные сохраняются. |
| **Авто-синхро пара** | Пара доверенных устройств с настроенной автоматической синхронизацией; устройство проверяет их доступность при запуске. |
| **Discovery** | Обнаружение устройств в сети (mDNS/UDP-broadcast). |
| **Indexer** | Компонент, сканирующий хранилище и считающий метаданные/хеши. |
| **Блок (Chunk/Block)** | Часть файла, полученная content-defined chunking; единица передачи и сравнения. |
| **Content-defined chunking** | Разбивка файла на блоки по содержимому (rolling hash), чтобы при изменении передавать только затронутые блоки. |
| **Merkle-дерево** | Дерево хешей для быстрого сравнения состояний хранилищ. |
| **Version vector** | Структура для отслеживания версий и обнаружения конфликтов при синхронизации. |
| **BEP** | Block Exchange Protocol — протокол обмена блоками в Syncthing, наш референс. |
| **Core (`Porta.Core`)** | Платформонезависимое ядро: вся логика без привязки к UI и ОС. |
