# Фича: применение конфликтов к файлам (срез C)

**Статус:** готово · **Слой:** `Porta.Core/Sync`

Связывает решение о конфликте ([15](15-conflict-resolution.md)) с реальной записью файлов.

## API

`SyncApplier.Apply(rootPath, local, remote, remoteDeviceId, blocks, versions?, clock?)`
→ `SyncApplyReport(Accepted, Skipped, Conflicts)`.

Для каждой удалённой версионированной записи:
- **Accept** → `FileAssembler.Write` (перезапись с архивом прежней версии через `IVersionStore`);
- **Skip** → ничего;
- **Conflict** → локальный файл не трогаем, удалённую версию пишем под именем
  `ConflictResolver.ConflictName` (обе версии сохранены).

## Границы среза

- Применение версионированного индекса к папке с учётом конфликтов — **с тестами**
  (реальные файлы: accept/skip/conflict).
- Обмен версионированными индексами по сети и персистентность версий между запусками —
  срез D (интеграция в `SyncProtocol`).

## Тесты

- Accept: удалённый доминирует → локальный перезаписан.
- Conflict: параллельные правки → локальный цел, рядом конфликтная копия с удалённым
  содержимым.
- Skip: локальный новее → файл не тронут, копий нет.
