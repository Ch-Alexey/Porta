# 34. Мелочи интерфейса

## Зачем

Пачка мелких долгов из срезов 25, 28, 29, 30. Каждый по отдельности не тянет на срез,
но вместе они — разница между «работает» и «понятно, что происходит».

| Долг | Откуда | Что не так |
|---|---|---|
| Кнопка «Пауза» не показывает состояние | 29 | Всегда написано «Пауза»; нажата она или нет — видно только по подписи под именем |
| Приглашение не протухает на экране | 30 | Токен живёт 5 минут, картинка висит вечно — истёкший QR выглядит рабочим |
| Папка загрузок проверяется только на пустоту | 28 | Несуществующий путь выясняется в момент приёма, а не при сохранении |
| Фильтры медиа по дате и размеру не выведены | 25 | Есть в ядре и покрыты тестами, но недоступны человеку |
| Пути в списке медиа обрезаются справа | 25 | Не видно как раз хвоста с именем папки |
| Отправка из «Медиа» не подключена | 25, 28 | Найденное фото нельзя отправить, хотя вся механика готова |
| Отзыв доверия не разрывает соединения | 29 | Идущий синк с отозванным устройством доработает до конца |

## Решения

**Пауза.** Кнопка показывает текущее состояние, как переключатель авто/ручной: «Пауза»
или «Продолжить».

**Протухание приглашения.** Токен несёт срок действия — показываем его рядом с QR и
убираем картинку, когда время вышло. Без таймера: пересчитываем при обращении к
свойству и по нажатию, а не крутим фоновой проверкой ради надписи.

**Папка загрузок.** При сохранении пробуем создать папку; не получилось — говорим об
этом сразу, а не через полчаса при первой передаче.

**Фильтры медиа.** В UI выходят «не старше N дней» и «не меньше N МБ» — то, чем реально
пользуются при поиске фотографий. Полные диапазоны дат оставляем в ядре.

**Пути.** Обрезаем **слева** (`TextTrimming` не умеет, поэтому режем в модели): хвост
пути — имя папки и файла — информативнее начала.

**Отправка из «Медиа».** Кнопка «Отправить найденное» перекладывает найденные файлы в
список отправки на вкладке «Передача». Не отправляет сама: получателя всё равно
выбирать там, и молча слать файлы по нажатию в другой вкладке — плохая идея.

**Отзыв доверия.** Отзыв отменяет идущие операции с этим устройством. Реализуется
через токен отмены на устройство: доверие проверяется при установке сессии, но уже
идущую сессию надо обрывать явно.

## Тесты

- Подпись кнопки паузы меняется вместе с состоянием.
- Просроченное приглашение не показывается; свежее — показывается.
- Несуществующая папка загрузок: внятное сообщение, значение не сохранено.
- Фильтры «не старше» и «не меньше» доходят до `MediaQuery`.
- Длинный путь обрезается слева с сохранением имени файла.
- «Отправить найденное» наполняет список отправки без дубликатов.
- Отзыв доверия отменяет операции с этим устройством и не задевает другие.
