# Фича: авто-синхронизация

**Статус:** готово (сквозной E2E-тест) · **Слой:** `Porta.Core/Sync`, `Porta.App.Desktop`

«Ощущение Dropbox»: при появлении доверенного устройства в сети хранилища синхронизируются
**автоматически**, без нажатия кнопки.

## Компоненты

- `ISyncController` (перенесён в `Porta.Core.Sync`) — общая абстракция запуска синка;
  её зовут и кнопка в UI, и авто-координатор. Реализация — `QuicSyncController` (голова).
- `AutoSyncCoordinator` (ядро) — подписан на `IDeviceDiscovery.PeerDiscovered`:
  - синкает только с **доверенными** устройствами (`IDeviceRepository.Get != null`);
  - **дедуплицирует** одновременные синки с одним устройством (не запускает второй, пока
    первый идёт);
  - авто-синк «тихий» — ошибки не всплывают наружу (видны при ручном синке).

Композиция — в [`Program.cs`](../../src/Porta.App.Desktop/Program.cs): координатор
создаётся с discovery + репозиторием устройств + `QuicSyncController`, стартует при
запуске, освобождается при выходе.

## Границы

- Синкает **все** локальные хранилища с доверенным устройством (per-link `auto_sync` из
  `storage_devices` пока не учитывается — нет UI для связывания хранилищ с устройствами).
- Триггер — только «устройство появилось». Синк по **локальным изменениям файлов**
  (FileSystemWatcher) и периодический — следующие срезы.
- Нет UI-индикатора «идёт авто-синк»/истории. Разовый статус — только у ручной кнопки.

## Тесты

- `AutoSyncCoordinator` (юнит): доверенное устройство → синк; чужое → игнор; повтор во
  время синка → один вызов; после завершения → может запуститься снова.
- `AutoSyncE2ETests` (интеграция): устройство B находит доверенное A по **реальному mDNS**
  и **автоматически** синхронизирует файл через **реальный QUIC** — без кнопки.
