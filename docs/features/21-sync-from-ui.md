# Фича: синхронизация из UI

**Статус:** готово (компонентно; сквозная GUI-проверка двумя узлами — вручную) ·
**Слой:** `Porta.App`, `Porta.App.Desktop`, `Porta.Core/Sync`

Замыкает сценарий: **нашли устройство → нажали «Синхронизировать» → папки синхронизировались**.

## Составляющие

### Многохранилищная отдача
`VersionedSync.ServeAsync` теперь принимает `resolveFolder(storageId) → путь?`: сервер
отдаёт **запрошенное** клиентом хранилище (а не заранее заданное). `null` → хранилище
недоступно, отдаётся пустой индекс. Проверено интеграционно (`Serves_the_requested_storage_by_id`).

### Фоновый приём (`BackgroundSyncListener`, десктоп-голова)
Слушает QUIC на порту 47100, в цикле принимает соединения и отдаёт хранилища доверенным
устройствам (`SyncService.ServeOnceAsync`, папка — из `StorageRepository`). Гейтится
`QuicTransport.IsSupported`; ошибки одного соединения не роняют приём; освобождается при выходе.

### Запуск синка (`QuicSyncController` : `ISyncController`, десктоп-голова)
По найденному `DiscoveredPeer`: выбирает адрес (предпочитает IPv4), поднимает
`SyncService` и тянет **все** локальные хранилища у пира. Возвращает краткий статус.

### UI
`DevicesViewModel.SyncWithFoundCommand` (кнопка «Синхронизировать» во вкладке
«Устройства») вызывает `ISyncController` для каждого найденного устройства и показывает
статус. `CanSync` включает кнопку, когда есть контроллер и найденные устройства.

Композиция — в [`Program.cs`](../../src/Porta.App.Desktop/Program.cs) (голова видит
инфраструктуру); ядро/VM зависят только от абстракций (`ISyncController`, `IDeviceDiscovery`).

## Границы

- Обе стороны должны быть **спарены** (доверять друг другу) — иначе `UntrustedPeerException`,
  отражается в статусе. «Довериться» по найденному (без токена) — пока нет.
- Синк по всем хранилищам скопом; выбор конкретного хранилища/папки в UI — позже.
- Требует libmsquic в рантайме (`DYLD_LIBRARY_PATH` на macOS) — поставка библиотеки не решена.
- Прогресс/отмена в UI, повторные периодические синки — позже.

## Тесты

- `VersionedSync`/`SyncService` отдают запрошенное хранилище по id (интеграция, QUIC).
- `DevicesViewModel.SyncWithFound` вызывает контроллер по каждому найденному устройству;
  `CanSync` учитывает наличие контроллера и устройств (VM, фейки).
- Приложение с приёмником и композицией проверено запуском.
