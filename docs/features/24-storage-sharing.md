# Фича: выборочный доступ (связывание хранилищ↔устройств)

**Статус:** готово · **Слой:** `Porta.Core/Sync`, `Porta.App`, `Porta.App.Desktop`

Заменяет «доверяешь устройству → делишь всё» на **выборочный доступ**: папка синхронизируется
только с теми устройствами, с которыми ей поделились.

## Модель

Связь хранилище↔устройство уже есть в БД (`storage_devices`, `StorageDeviceLink`). Теперь
она используется:
- `StorageSharing.SharedWith(storages, device)` (ядро) — какие хранилища расшарены устройству.
- Синк (ручной и авто) через `QuicSyncController` касается **только расшаренных** хранилищ.
  Нет связи — устройство ничего не получает.

## UI

Вкладка «Хранилища»: панель «Поделиться папкой с устройством» (выбор хранилища + выбор
доверенного устройства + «Поделиться»/«Убрать доступ»); в строке хранилища показан
«Общий доступ: …». Расшаривание ставит `auto_sync = true` (поделился = авто-синкается).

## Границы (осознанно)

- Поделился = авто-синк (отдельного тумблера auto/manual per-link пока нет — не раздуваем).
- **`FileSystemChangeNotifier` наблюдает папки хранилищ, существующие на старте.** Новые
  хранилища подхватятся после перезапуска (тот же край, что в [23](23-file-change-sync.md);
  переинициализация watcher при изменении списка — отдельный небольшой срез).

## Тесты

- `StorageSharing`: возвращает только связанные хранилища; без связей — пусто (ядро).
- `StoragesViewModel`: список доверенных для выбора; «Поделиться» создаёт связь и показывает
  её; «Убрать доступ» удаляет (VM, in-memory репозитории).
