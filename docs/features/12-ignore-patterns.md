# Фича: игнор-паттерны

**Статус:** первый срез готов · **Слой:** `Porta.Core/Indexing`, `Porta.Core/Sync`

Готово: `IgnoreRules` (имя/путь-паттерны, глобы `*`/`**`/`?`, комментарии), фильтрация в
`FolderScanner.Scan(root, ignore)`, проброс в `SyncProtocol.ServeAsync/PullAsync`.
11 тестов (правила, скан, синк служебной папки).

Закрывает повторяющийся долг (индексатор, версионирование): служебные папки (напр.
`.porta/versions`) и нежелательные файлы не должны сканироваться и синхронизироваться.
Есть в [функциональной картине](00-functionality.md) как настройка хранилища.

## Синтаксис (подмножество gitignore)

- Пустые строки и `# комментарии` пропускаются.
- **Имя/сегмент** (без `/`): матчит любой сегмент пути. `node_modules`, `*.tmp`, `*.log`.
  Игнор папки по имени исключает и всё её содержимое (сегмент встречается в путях внутри).
- **Путь** (со `/`): матчит путь и его потомков, привязка к корню хранилища.
  `/build/`, `docs/*.bak`, `cache/tmp`.
- Глобы: `*` (в пределах сегмента), `**` (через сегменты, только для путей), `?`.
- Завершающий `/` (маркер папки) принимается лениво.
- **Регистрозависимо** (Ordinal) — для детерминизма между устройствами.
- Не поддержано пока: отрицание `!` (пометка на будущее).

## API

- `IgnoreRules(patterns)` — компилирует правила; `IsIgnored(relativePath)`; `IgnoreRules.Empty`.
- `FolderScanner.Scan(root, IgnoreRules?)` — пропускает игнорируемые файлы.
- `SyncProtocol.ServeAsync/PullAsync(..., IgnoreRules?)` — одинаковые правила с обеих
  сторон (иначе индексы разойдутся).

## Границы среза

- Сопоставление + фильтрация в скане + проброс в синк — **с тестами**.
- **Не спускаемся** в игнорируемые папки при обходе (перф) — пока фильтруем после
  перечисления; прунинг дерева — долг.
- Загрузка правил из файла (`.portaignore`) и из настроек хранилища — позже.
- Отрицание `!`, регистронезависимость по желанию — позже.

## Тесты

- `IgnoreRules`: имя-паттерн на любом уровне; `*.tmp`; `.porta/` исключает поддерево;
  привязанный `/build/` не трогает `src/build`; путь-глоб `docs/*.bak` не переходит `/`;
  комментарии/пустые пропускаются.
- `FolderScanner`: игнорируемые файлы не попадают в индекс.
- `SyncProtocol`: игнорируемая служебная папка не синхронизируется.
