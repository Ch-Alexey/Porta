# Фича: синхронизация по локальным изменениям файлов

**Статус:** готово · **Слой:** `Porta.Core/Sync`, `Porta.Infrastructure`

Готово: `IChangeNotifier`, `AutoSyncCoordinator` помнит найденных и синкает на изменение,
`FileSystemChangeNotifier` (watcher + дебаунс), проброс в голове. Тесты: реакция
координатора (юнит) + подъём сигнала на запись файла (интеграция).

Закрывает пробел «постоянного синка»: раньше авто-синк запускался только при появлении
устройства. Теперь при **изменении файла в хранилище** синк запускается с уже известными
(найденными в сети) доверенными устройствами.

## Компоненты (минимально)

- `IChangeNotifier` (ядро) — событие «в хранилищах что-то изменилось».
- `AutoSyncCoordinator` (ядро) теперь:
  - помнит найденные доверенные устройства (`PeerDiscovered`/`PeerLost`);
  - на `IChangeNotifier.Changed` синкает со всеми известными (с той же дедупликацией).
- `FileSystemChangeNotifier` (инфраструктура) — `FileSystemWatcher` по папкам хранилищ с
  **дебаунсом** (много ФС-событий → один сигнал через паузу).

## Границы (осознанно узкие)

- Наблюдаются папки хранилищ, **существующие на момент запуска**; новые хранилища
  подхватятся после перезапуска (пока так — не раздуваем).
- Дебаунс фиксированный; тонкая настройка — позже.

## Тесты

- `AutoSyncCoordinator`: на `Changed` синкает известных доверенных; без известных — ничего;
  дедуп сохраняется.
- `FileSystemChangeNotifier` (интеграционно): запись файла поднимает `Changed`.
