# ADR-0006: Транспорт — QUIC (шифрование обязательно)

- **Статус:** принято
- **Дата:** 2026-07-30
- **Заменяет:** ранний вариант «начать с TLS/TCP, QUIC позже» (см. [обзор](../architecture/00-overview.md)).

## Контекст

Весь обмен между устройствами должен быть зашифрован. Нужен защищённый транспорт,
хорошо работающий и на десктопе, и на мобильных (где сеть может меняться — Wi-Fi ↔
мобильный интернет). Пользователь явно предпочёл QUIC.

## Решение

Транспорт — **QUIC** (`System.Net.Quic` в .NET, поверх msquic).

Почему подходит:

- **Встроенное шифрование (TLS 1.3)** — незашифрованного режима у QUIC нет в принципе.
- **Мультиплексирование потоков** в одном соединении — удобно для параллельной
  передачи блоков разных файлов без head-of-line blocking.
- **Connection migration** — соединение переживает смену IP/сети, что важно для
  мобильных устройств.

## Модель доверия поверх QUIC

- Личность устройства (криптоключи) используется для самоподписанного сертификата.
- При рукопожатии стороны проверяют сертификат по **закреплённому публичному ключу**
  (pinning) доверенного устройства, а не по цепочке CA. Чужие/неизвестные ключи
  отклоняются.
- Это та же схема доверия, что у Syncthing, только транспорт — QUIC.

## Последствия и риски (проверить при реализации)

- **Доступность msquic по платформам.** `System.Net.Quic` требует наличия msquic.
  На desktop (Win/Linux/macOS) обычно ок; на iOS/Android нужно проверить поддержку и
  способ поставки библиотеки. Заложить абстракцию транспорта, чтобы при проблемах на
  какой-то платформе можно было подставить fallback (TLS/TCP), не трогая протокол.
- **Тип ключа сертификата.** TLS 1.3 в QUIC на разных стеках по-разному поддерживает
  Ed25519; возможно, для сертификата возьмём ECDSA P-256. Ключ для *подписи/идентити*
  и ключ *сертификата* — решим на этапе Identity/Transport.
- **Порт/файрвол** — QUIC поверх UDP; учесть в discovery и сетевых настройках.

## Абстракция

В ядре вводим интерфейс транспорта (открыть защищённое соединение к доверенному
устройству, получить дуплексные потоки). Реализация по умолчанию — QUIC. Протокол
сообщений (MessagePack, [ADR-0004](0004-protocol-format.md)) от транспорта не зависит.
