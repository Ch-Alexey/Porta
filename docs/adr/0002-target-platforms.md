# ADR-0002: Целевые платформы

- **Статус:** принято
- **Дата:** 2026-07-30

## Контекст

Приложение должно запускаться «на любом устройстве» и создавать на нём локальное
хранилище, участвующее в обмене.

## Решение

Поддерживаем равнозначно: **Windows, macOS, Linux, iOS, Android**.

Ни одна платформа не считается второстепенной на уровне архитектуры. При этом
разработку ведём так, чтобы ядро было готово раньше UI, а UI-платформы можно было
включать поэтапно (см. [roadmap](../roadmap.md)) без переделки ядра.

## Последствия

- Никаких платформозависимых API в ядре — только через абстракции.
- CI в перспективе должен собирать под все таргеты.
- Особое внимание — различиям в файловых системах, правах доступа (особенно
  iOS/Android — песочница, доступ к галерее через системные разрешения) и работе
  в фоне.
