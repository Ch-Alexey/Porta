# ADR-0001: UI-фреймворк — Avalonia UI

- **Статус:** принято
- **Дата:** 2026-07-30

## Контекст

Нужен кроссплатформенный UI на .NET, работающий на Windows, macOS, Linux, iOS и
Android из одной кодовой базы. Приложение — «врата» для передачи файлов между
устройствами, десктоп и Linux важны наравне с мобильными.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Avalonia UI** | Все платформы включая **Linux desktop**; зрелый; своя отрисовка (единый вид); большое комьюнити; XAML + MVVM | Нативный вид не «из коробки» (рисует сам) |
| .NET MAUI | Официальный от Microsoft; силён на мобилках и Windows/macOS | **Нет Linux desktop**; десктоп исторически слабее |
| Uno Platform | Все платформы + WebAssembly | Более сложная сборка; меньше комьюнити |

## Решение

Берём **Avalonia UI**. Решающий фактор — полноценная поддержка Linux desktop и
равномерное качество на всех платформах, что критично для приложения с упором на
десктоп и P2P между разнородными устройствами.

## Последствия

- UI пишем на XAML + паттерн MVVM.
- Вся бизнес-логика выносится в платформонезависимое ядро `Porta.Core`, UI остаётся тонким.
- Нативные возможности платформ (галерея, уведомления, фоновые сервисы) закрываем
  через абстракции в ядре и платформенные реализации.
